# Word Garden 🌱

English vocabulary practice for Hebrew-speaking learners.

## Play
Open the published GitHub Pages site after enabling it in **Settings → Pages → Deploy from a branch → main → /(root)**.

## Features
- Hebrew prompts with typed English spelling
- Shows the correct spelling after a mistake; repeats missed words until mastered
- Word library and progress stored in the browser
- Crossword / word-wheel game

## Notes
Progress is stored locally in each browser, not synchronized between devices.

This is a static website. Open `index.html` to run it locally.
